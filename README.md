# どてっぱん マニュアル動画一覧

加盟店・運営会社向けのマニュアル動画一覧ページです。
Googleスプレッドシート「マニュアル動画リスト」を元に、`index.html` を自動生成しています。

## 仕組み

- **データ元**: Googleスプレッドシート(マニュアル動画リスト)
- **生成**: `build.py` がスプレッドシートをCSVで読み取り、`index.html` を生成
- **自動更新**: GitHub Actions が毎朝9時(日本時間)にスプレッドシートを確認し、
  変更があればページを自動更新(`.github/workflows/update.yml`)
- **公開**: GitHub Pages

## 手動で今すぐ更新したいとき

GitHubのリポジトリページ → 「Actions」タブ → 「ページ自動更新」→ 「Run workflow」ボタン。
1〜2分でページに反映されます。

## 動画の追加方法

スプレッドシートに行を追加するだけです:

1. 動画をYouTubeに限定公開でアップロード
2. スプレッドシートの「タイトル」「URL」を記入し、「アップロード済」にチェック(TRUE)
3. 翌朝9時に自動反映(急ぐ場合は上記の手動更新)

新しく追加された動画には、14日間「NEW」バッジが付きます。

## 注意事項

- このページのURLは従業員・加盟店・運営会社の関係者のみに共有してください
- 検索エンジンには登録されない設定(noindex)になっています
